# 🌱 AI-Powered Smart Integrated Farming Intelligence System (SIFIS)

> **Empowering Farmers with Artificial Intelligence, Smart Monitoring, and Sustainable Agriculture**

---

## 📖 Overview

The **AI-Powered Smart Integrated Farming Intelligence System (SIFIS)** is a modern smart farming web application designed to help farmers make informed agricultural decisions using Artificial Intelligence (AI), weather forecasting, and intelligent farming technologies.

The platform provides real-time recommendations for crop selection, plant disease detection, irrigation planning, weather monitoring, and market price updates, helping improve productivity while promoting sustainable farming practices.

---

## 🎯 Project Objectives

* Improve agricultural productivity using AI.
* Provide intelligent crop recommendations.
* Detect plant diseases from uploaded images.
* Monitor weather conditions.
* Support smart irrigation decisions.
* Display crop market prices.
* Promote sustainable and data-driven farming.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/SIFIS.git
```

## Navigate to Project

```bash
cd SIFIS
```

## Install Backend Dependencies

```bash
npm install
```

## Run Backend

```bash
npm run dev
```

## Open Frontend

Run using **Live Server** in Visual Studio Code.
