# SIFIS Frontend

This project contains a premium frontend experience for the AI-Powered Smart Integrated Farming Intelligence System (SIFIS).

## Features
- Responsive multi-page UI
- Premium agriculture dashboard
- Bootstrap-based layout
- Chart.js visualizations
- Leaflet.js map
- Dark mode toggle
- Smooth scrolling and animated reveals

## Run Locally
Open the project folder in VS Code and use Live Server to launch the index page.
